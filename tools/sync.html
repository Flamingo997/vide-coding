豆瓣数据录入工具

手动录入豆瓣评分/导演/演员/剧情 → 合入 data.json → 导出替换站点数据

使用说明：由于 Cloudflare 服务器无法访问豆瓣，采用纯手动录入方式。 ① 在豆瓣网页搜索影片，右键把详情（评分、导演、演员、剧情简介、海报图地址）复制/照抄填入下表； ② 填完一行点击对应 💾 保存； ③ 全部完成后点下方 ⬇️ 导出 data.json 下载，用下载的文件替换站点根目录的 data.json； ④ 执行 git commit + push 即可上线。海报图地址可用豆瓣 http://img3.doubanio.com 开头、或任何可公开访问的图床 URL。
⬇️ 预览 / 下载导出的 data.json
